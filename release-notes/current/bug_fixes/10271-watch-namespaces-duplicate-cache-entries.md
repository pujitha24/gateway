Fixed the Kubernetes provider's cache configuration when `watch.type` is `Namespaces`: duplicate per-type cache entries made the cache scope of Secrets, ConfigMaps, Services, EndpointSlices, ServiceAccounts and Deployments random on each start, so the controller could fail to become Ready or miss resources in its own namespace. The Helm chart now also grants the controller namespace Role EndpointSlice read access in Gateway Namespace Mode with `watch.namespaces`.
